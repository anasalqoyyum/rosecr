About RoseCR

Windows-first OCR translation overlays for Japanese and English games.

Local OCR extracts text. Codex translates eligible text and bounded text context after you press Play or enable Auto.

RoseCR stays outside the game process. No injection, memory reading or text hooks.

This is a design prototype. PR #2 provides the M0 utility shell and capture probe. It does not provide the full translation pipeline.

State is part of the design.

Auto intent, capture health and overlay visibility are separate facts.

Behavior contract
Startup / idle
Idle · Auto off

Restore durable preferences. Wait for Play or Auto before starting OCR or cloud work.

Prerequisite missing

Name the missing prerequisite beside the disabled action. Offer setup, account sign-in or target selection.

First result pending
Translating…

Keep source text visible until the complete translation is ready. Never obscure it with an empty plate.

Updating
Updating…

Keep the last valid translation readable but dimmed while the update is pending. Commit the full result atomically.

Auto capturing
Capturing · Auto on

Show Auto on immediately. Report Capturing only when capture is actually running. Play forces a refresh.

Overlays hidden
Hidden · Auto on

Visibility changes do not disable Auto. Keep its active state visible in the controller.

Target unavailable
Waiting · Auto on

Clear overlays, retain the target and region, and reconnect to a uniquely matching returning window. Retry belongs in the controller.

Update failed
Retry translation

Retry transient failure once. Then reveal current source and explain recovery in the controller. Never show a previous source's translation as current.

Geometry changed
Realigning…

Hide translated output during move, resize or DPI changes. Require matching fresh geometry before revealing it.

Dense layout
Edge callout

Wrap, expand, reposition and shrink within the readable minimum first. Preserve full text without collisions or silent truncation.

Clear
Output cleared

Remove overlays and local one-shot watchers. Reject late results from cleared work. Auto's next eligible source generation may produce a new translation.

Implementation mapping
M0

Safe Windows foundation

Utility shell, durable preferences, Auto off at launch, settings, shortcuts, explicit-window capture and a harmless passive marker.

PR #2 records the native Windows helper decision. Its capture probe does not perform OCR or translated text replacement.

M1

Durable local OCR

Saved game region, supervised OCR sidecar and local text extraction.

M2

First Codex translation

Account sign-in, account-reported model choices and one-shot translated overlays.

M3

Realtime translation quality

Change-driven Auto, stable text tracking, bounded context, batching and cache correctness.

M4

Capture and overlay productization

Production recovery, DPI alignment, collision handling and overlay accessibility controls.

M5

Privacy, setup and release

Verified OCR downloads, guided setup, one-shot validation, private diagnostics and Windows release checks.

Review comments inform the states

Show Auto intent immediately, but never claim capture is running before it is. Target changes and Clear invalidate prior output. Shortcut conflicts must appear on the first render. Capture-probe lifecycle and diagnostics must agree.

These are design implications of PR #2 review comments. They are not claims that every reviewed implementation issue is resolved.

Keep deferred UI out of v1

No inspect panel, dictionary, history, learning workflow, CAT-Translate, provider marketplace or BYOK API form.
